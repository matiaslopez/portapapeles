Estructura básica

  cout << "Hola " << nombre;

Por valor / referencia / puntero
void porValor(int x)      { x = x*2; }  // copia
void porRef(int& x)       { x = x*2; }  // modifica
void porPtr(int* p)       { *p = *p*2; }
void porConstRef(const string& s) { }  // sin copia

int n = 5;
porRef(n);        // n = 10
porPtr(&n);       // n = 20 (pasar dirección)

Toda función puede tener varios parámetros de salida usando referencias.

Arrays estáticos — colecciones de tamaño fijo
Declaración e inicialización
int arr[5];                    // sin init (basura)
int arr[5] = {1, 2, 3, 4, 5};
int arr[]  = {1, 2, 3};       // tamaño inferido: 3
int zeros[10] = {};           // todo en 0
const int N = 100;  int datos[N];  // tam. constante
Recorrido y acceso
arr[0];    arr[n-1];   // primero / último
for (int i = 0; i < 5; i++) cout << arr[i] << " ";
Arrays 2D (matrices)
int mat[3][4];               // 3 filas, 4 columnas
int mat[2][3] = { {1,2,3}, {4,5,6} };
mat[0][0] = 1;                // fila, columna
for (int i=0;i<3;i++)
  for (int j=0;j<4;j++) cout << mat[i][j];
Pasar a función
void llenar(int arr[], int n) {   // tamaño aparte
  for (int i=0;i<n;i++) arr[i]=0;
}  // el array siempre se pasa por referencia
Los arrays no guardan su tamaño ni controlan límites: acceder fuera de rango es comportamiento indefinido.
Punteros — operaciones — direcciones de memoria
Operadores fundamentales
int  x = 10;
int* p = &x;    // & = dirección de x
*p = 20;        // * = valor en la dirección
cout << p;      // dirección (hex)
cout << *p;     // 20  (desreferencia)
Puntero a struct
Nodo  m;  m.dato = 5;    // variable normal → .
Nodo* p = &m;
p->dato;                  // puntero → ->
Aritmética de punteros
int arr[] = {10, 20, 30, 40};
int* p = arr;    // apunta a arr[0]
p++;             // avanza sizeof(int) bytes
cout << *p;      // 20 (arr[1])
// arr[i] equivale a *(arr + i)
Puntero a puntero
int x = 5;  int* p = &x;  int** pp = &p;
cout << **pp;    // 5
Memoria dinámica — heap, new / delete
Variable y array dinámico
int* p = new int;       *p = 42;
int* p2 = new int(42);      // alocar + init
delete p;  p = nullptr;     // liberar (obligatorio)

int n;  cin >> n;
int* arr = new int[n];      // tamaño en runtime
for (int i=0;i<n;i++) arr[i]=i;
delete[] arr;  arr = nullptr;  // delete[] p/arrays
Struct en heap (nodo típico)
struct Nodo { int dato; Nodo* sig; };

Nodo* n = new Nodo;
n->dato = 5;  n->sig = nullptr;
delete n;  n = nullptr;
newdelete
new T→delete p
new T[n]→delete[] p
Leak: olvidar delete. Doble free: liberar dos veces. Dangling: usar el puntero tras liberarlo — asignar nullptr ayuda a detectarlo.
Strings — <string>
Declaración y operaciones básicas
string s = "hola";
string vacio;                // == ""

s.length();  s.size();       // cant. de caracteres
s[0];                        // acceso como array: 'h'
s.empty();                   // true si length()==0

string t = s + " mundo";     // concatenar
s += "!";                    // agregar al final
Entrada y recorrido
cin >> s;             // una palabra (hasta espacio)
getline(cin, s);       // línea completa
for (char c : s) cout << c;  // recorrido
Comparación, búsqueda y substrings
s == "hola";   s != "chau";  // comparación
s < t;                       // orden lexicográfico

s.substr(0, 4);   // "hola" (desde 0, 4 caract.)
s.substr(1);      // desde índice 1 hasta el final

s.find("mun");    // índice donde empieza, o
                   // string::npos si no está
Conversión
to_string(42);               // int → string
stoi("42");  stod("3.14");   // string → número
string::npos = valor devuelto por find cuando no se encontró la subcadena.
